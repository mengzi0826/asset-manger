# 资产管家

本机运行的个人资产记录与分析工具。数据只写在本机 SQLite，不依赖云账号。

面向日常复盘：净资产、分类构成、证券持仓与今日盈亏、净值曲线、到期提醒。

**技术栈**：Next.js 14（App Router）· TypeScript · Tailwind CSS · SQLite（better-sqlite3）· Recharts

源码：<https://github.com/mengzi0826/asset-manger>  
给后续开发者 / AI 的硬约定见 [AGENTS.md](./AGENTS.md)。

---

## 能做什么

五个页面，对应顶部导航。

**总览** — 净资产（总资产 − 总负债）、较上次快照的涨跌、CNY / USD / HKD 原币汇总。资产构成饼图与净值走势并排。摘要瓦片：累计变化、浮动盈亏、证券今日、加权年化；60 天内到期列表。配置建议与最近变动。底部显示汇率 / 股价上次更新时间；拉取失败或过期会出提示。

**证券** — 独立看板：总市值、今日盈亏、浮动盈亏、按市场（沪深 / 港股 / 美股）分组。总市值走势来自每日组合快照；浮动盈亏走势由历史价格重建。持仓行带 mini sparkline。

**资产** — 全量列表，按大类 tab，可再按币种、账户过滤。先在大类下建账户（如「工行活期」「雪球」），再往账户里加资产。证券支持按名称/代码搜索（东方财富）自动补全，并可在详情页做增持、减持、清仓（可选联动同币种现金）。

**历史** — 完整净值曲线，可手动记一条当日快照。全量变动日志（新增 / 修改 / 删除），修改显示字段级 diff。

**设置** — 基准货币（CNY / USD）、聚合数据 AppKey、汇率刷新或手动覆盖、股票价格刷新与失败日志、JSON 备份导入导出。

深浅色主题；涨跌颜色按中国市场惯例：**红涨绿跌**。

## 快速上手

需要 Node.js 18+。

```bash
git clone https://github.com/mengzi0826/asset-manger.git
cd asset-manger
npm install
npm run dev
```

浏览器打开 <http://127.0.0.1:3000>。默认只绑本机，不向局域网暴露。

生产：

```bash
npm run build
npm run start
```

改端口：编辑 `package.json` 里 `dev` / `start` 的 `-p`。

macOS 若报 `EMFILE: too many open files`，先执行 `ulimit -n 10240` 再启动。

## 外部数据

汇率与股票行情来自 [聚合数据](https://www.juhe.cn)，两套产品、两枚 AppKey，在 **设置** 页分别填写（也可只用环境变量，库内保存优先）：

| 用途 | 环境变量 |
| --- | --- |
| 全球汇率 | `JUHE_FX_APPKEY` |
| 股票数据 | `JUHE_STOCK_APPKEY` |

不配 Key 时，对应刷新会跳过，已有缓存和手填价格仍可用。

- **汇率**：支持 CNY / USD / HKD。距上次非手动拉取满 8 小时后自动再拉；失败则继续用缓存。也可在设置里手填一对汇率（标记为「手动」）。
- **股票**：工作日北京时间 10:00、14:00 两个锚点各最多自动一轮；**周六日自动跳过**，设置里的手动刷新仍会请求。无代码或无法识别的证券会被跳过。单标的失败不会清空该行已有涨跌。

进程在跑时，后台约每分钟检查一次是否到期该拉（不必一直开着某个页面）。设置里的「刷新」是强制拉取。

证券搜索走东方财富公开 suggest，不需要聚合 Key。

## 数据存在哪

| 路径 | 说明 |
| --- | --- |
| `data/assets.db` | 主库，首次启动自动创建 |
| `data/assets.db-wal` / `-shm` | WAL 运行时文件 |

`data/` 已 gitignore，不要提交。

**备份（推荐）**：设置 → 数据备份 → 导出 JSON（含资产、快照、证券日线等），定期另存。

**恢复**：同一入口导入。**合并**按主键 upsert；**覆盖**会清空资产/账户/汇率/设置/变动日志/快照/证券日线与刷新日志后再导入（分类表保留后按文件 upsert）。旧版备份没有日线字段也可以导入，证券走势图会缺历史点。

也可在应用关闭后直接复制 `data/assets.db`。

## 资产怎么估值

| 类型 | 算法 |
| --- | --- |
| 现金、存款/理财、基金、加密货币、负债、其他 | 用填写的 `金额` |
| 证券 | `份额 × (当前价，没有则用买入均价)` |
| 净资产 | 非负债合计 − 负债合计 |

展示统一换算到基准货币。缺汇率、汇率过期或股价拉取失败时，总览会提示，去设置里刷新或手填。

证券「今日盈亏」只计入行情会话日为**今天**（北京）的持仓；股数按**当日第一次改仓前**的持仓（当天卖掉的部分仍算进今日盈亏）。没有今日行情（含休市）时，总览「证券今日」和明细都是 **—**，不会显示成赚了 0 元。

## 常见问题

**部分汇率缺失**  
到「设置 → 汇率管理」点刷新，或手动录入该币对。

**股票价格没动**  
确认股票 AppKey 已配、产品已在聚合控制台开通。工作日 10:00 前不会自动拉；10:00～14:00 若已拉过上午那一档，要等到 14:00。周六日自动跳过，可用设置里的手动刷新拉取上个交易日收盘价。

**总览「证券今日」是 —**  
没有份额大于 0 的证券，或这些标的的行情会话日不是今天（休市、刷新失败、接口没给交易日）。这不是「今天涨跌为 0」。

**总览提示汇率/股价过期或失败**  
看提示原文。常见是聚合额度/Key，或本机 Fake-IP 导致 `ENOTFOUND`。数字仍按缓存计算，不要当成刚刷新过。

**只有部分标的有今日涨跌**  
该次刷新里失败的标的不会 UPDATE，其它成功写入的行不受影响。看设置页的失败日志。

**本机开了 Clash 一类 Fake-IP 代理，刷新报 ENOTFOUND**  
Node 的 `fetch` 不走系统代理。这是本机网络环境问题，不是 Key 配错。参见 [AGENTS.md](./AGENTS.md) 的网络一节。
